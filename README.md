# AppJogoDaVelha

Projeto desenvolvido em **.NET MAUI** que implementa o clássico **Jogo da Velha** para dispositivos móveis e desktop.

## Funcionalidades

* Tabuleiro 3x3 interativo.
* Alternância automática entre os jogadores **X** e **O**.
* Verificação de vitória em linhas, colunas e diagonais.
* Detecção de empate.
* Reinício automático da partida após o término do jogo.

## Tecnologias Utilizadas

* C#
* .NET MAUI
* XAML

## Como Funciona

Ao clicar em uma posição do tabuleiro, o sistema registra a jogada do jogador atual. Após cada movimento, o aplicativo verifica se houve vencedor ou empate. Quando a partida termina, uma mensagem é exibida e o tabuleiro é limpo para uma nova rodada.

## Objetivo

Praticar conceitos de desenvolvimento mobile com .NET MAUI, manipulação de eventos, componentes visuais e lógica de programação utilizando matrizes e estruturas de controle.
